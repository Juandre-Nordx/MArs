# v0.2.2.3 — Automatic electrical connections

Electrical cables now connect automatically when placed directly beside any cardinal side of a building with an electrical system. This includes production companies, homes, solar arrays and batteries, across their full footprints. Diagonal tiles and gaps do not connect. Buildings without an electrical system, such as warehouses, do not attach. Construction costs are unchanged; no separate connector fee is charged.

All electrical contacts on one building share an internal bus. Branches touching opposite sides merge into one network before allocation, so solar generation, battery capacity and stored energy are counted once. Disabling or removing one contact keeps a building connected while another live contact remains. The last contact disconnects it. Changing topology does not create energy or move physical reserves between batteries.

The inspector and selected-building markers now show electrical contacts on all sides, matching the simulation. Citizen advice explains side-adjacent cables and a connection to solar or batteries. Water, oxygen and road behavior is preserved.

## Save and deployment compatibility

Gameplay schema remains version 4. Network rules advance to version 4; saves using rules 1, 2 or 3 rebuild derived networks while preserving buildings, infrastructure, residents, pending arrivals and physical resources. Older schema migrations remain supported. No SQL migration is required. Dockerfile, Compose, Railway settings and Prisma schema are unchanged.

Display/API release: `0.2.2.3`. Private npm workspace versions use valid SemVer `0.2.2+3`. The lockfile updates version metadata without dependency upgrades.
