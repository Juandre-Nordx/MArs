# MARS: FIRST COLONY — V0.3.1

## Industrial Expansion, Automated Mining and Resource Economy

Continue development of the existing MARS: FIRST COLONY project hosted on Railway.

The existing game has:

- Isometric terrain
- Starship landing and starter settlement
- Colonists and immigration
- Functional oxygen, water, food and electricity
- Water and oxygen pipe networks
- Electrical cables and power distribution
- Roads
- Construction and building inspection
- Save/load functionality

Inspect the actual repository before changing anything. Treat this description as the intended baseline and verify which systems are implemented.

**Do not rebuild the game or replace existing systems.**

## Main objective

Expand the colony from a small survival settlement into a functioning automated industrial economy.

The player must be able to explore a large Mars map, discover underground and surface minerals, build mines, operate autonomous drones, transport resources, store minerals, refine raw materials and manufacture useful products.

### Phase 1 — Expand the world

1. Increase the supported world size to 512 × 512 tiles.
2. Implement chunk-based terrain generation and rendering.
3. Only render visible chunks and nearby animated objects.
4. Preserve the existing isometric projection and camera.
5. Add new regions: plains, crater fields, rocky highlands and ice-bearing terrain.
6. Implement deterministic generation from a world seed.
7. Add fog of war and exploration state.
8. Generate surface and subsurface mineral deposits.
9. Ensure every new map has accessible starter resources.
10. Preserve existing colonies using a versioned map-expansion migration.

Do not regenerate or move existing buildings, roads, pipes, cables or deposits when an old save is upgraded.

The world should use chunk coordinates and global tile coordinates so future map expansion remains practical.

### Phase 2 — Geological resources

Implement a data-driven geological resource registry.

Initial resources:

- Iron-bearing ore
- Aluminium-bearing ore
- Copper ore
- Lithium-bearing ore
- Silicon-bearing regolith
- Carbon-bearing material
- Titanium ore
- Sulfur-bearing material
- Water ice
- Rare uranium-bearing deposits

Every deposit requires:

- Unique ID
- Resource ID
- World position
- Surface or subsurface classification
- Estimated depth
- Richness
- Initial quantity
- Remaining quantity
- Required extraction technology
- Discovery status

Resource reserves must be finite and persistent.

Atmospheric CO₂ is obtained using atmospheric collection equipment rather than mineral mining.

Hydrogen, oxygen and methane are processed materials, not ordinary mineral deposits.

### Phase 3 — Scanning and exploration

Add a geological scanning interface.

Support three scanning modes:

1. Surface scan
2. Subsurface scan
3. Deep geological scan

Players must be able to select a region for scanning.

Survey drones travel to the selected area and perform scanning over time.

Scanner range, scan duration, power use and detection capability must be configurable.

Add a resource overlay displaying:

- Discovered resource type
- Estimated reserves
- Richness
- Depth
- Extraction requirements

Unknown deposits remain hidden.

Scanning reveals pre-generated deposits and must never create new resources.

### Phase 4 — Drone automation

Create an autonomous drone system.

Initial drone types:

- Survey drone
- Mining drone
- Drilling drone
- Cargo rover
- Construction drone

Each drone needs:

- Unique ID
- Drone type
- Position
- Current task
- Operational state
- Battery capacity
- Current charge
- Cargo capacity
- Movement speed
- Condition
- Assigned home station

Implement a central job dispatcher.

Jobs have priorities and states.

Examples:

- Scan region
- Extract ore
- Collect mined material
- Deliver material
- Construct facility
- Repair infrastructure
- Return for charging

Drones must not require manual control for every journey.

Implement task assignment, pathfinding, charging, cargo transfer and failure recovery.

No drone may perform two exclusive jobs simultaneously.

A drone with insufficient energy must recharge before continuing.

### Phase 5 — Mining

Add mining buildings:

1. Surface extraction site
2. Open-pit mine
3. Underground mine entrance
4. Deep drilling station
5. Water-ice extraction drill
6. Atmospheric CO₂ collector

Mines require:

- A compatible deposit or atmospheric resource
- Construction materials
- Electricity
- Drone availability
- Output storage capacity
- Operational condition

Mining must reduce the deposit's remaining reserves.

Mining productivity depends on deposit richness, equipment capability, power and assigned drones.

Underground mining should use an abstract depth model. A full underground 3D world is not required.

### Phase 6 — Storage and transportation

Introduce specialised storage:

- Raw mineral warehouse
- Refined material warehouse
- Water tank
- Oxygen tank
- Hydrogen tank
- Methane tank
- Battery storage
- General cargo depot

Raw ore, refined solids, liquids, gases and manufactured goods must be represented separately.

Use existing roads for preferred ground vehicle routes.

Use existing pipes to transport compatible liquid and gaseous resources.

Use existing electrical networks to provide equipment power.

Existing water pipes and oxygen pipes must retain their resource-specific roles.

Add separate hydrogen and methane pipeline types, or a validated configurable pipeline system that prevents incompatible materials from mixing.

Storage containers and transport networks must have finite capacities.

Cargo drones and rovers carry solid goods between mines, refineries, factories and warehouses.

Transport must use real inventory transfers rather than instantly moving resources across the map.

### Phase 7 — Industry and manufacturing

Create a data-driven manufacturing system.

Initial facilities:

- Ore refinery
- Metal smelter
- Silicon processing plant
- Carbon processing plant
- Battery factory
- Solar panel factory
- Water purification plant
- Electrolysis plant
- Methane synthesis plant
- Fuel liquefaction and storage facility

Initial products:

- Refined iron
- Refined aluminium
- Refined copper
- Refined lithium
- Processed silicon
- Processed carbon
- Steel
- Battery packs
- Solar panels
- Purified water
- Hydrogen
- Oxygen
- Methane
- Liquid oxygen
- Liquid methane

Recipes must specify input resources, output resources, production duration, energy demand and required building.

Representative simplified recipes:

Battery pack:

- 2 refined lithium
- 1 refined copper
- 1 processed carbon
- Produces 1 battery pack

Solar panel:

- 3 processed silicon
- 2 refined aluminium
- 1 refined copper
- Produces 1 solar panel

Water purification:

- 5 units raw water from melted ice
- Produces 4 units purified water

Electrolysis:

- Consumes purified water and electricity
- Produces hydrogen and oxygen
- Uses configurable gameplay-balanced mass ratios

Methane production:

- Consumes hydrogen and captured CO₂
- Produces methane and water
- Requires electricity and the methane synthesis facility

Use plausible mass-conserving reactions where feasible, but keep resource quantities manageable for gameplay.

Factories must stop when materials, power, transport access or storage are unavailable.

### Phase 8 — Industrial water extraction

Expand the current water economy.

The player should be able to:

1. Discover underground water ice.
2. Construct an ice extraction drill.
3. Supply electricity.
4. Extract ice.
5. Melt and purify the ice.
6. Store purified water.
7. Connect the facility to the existing water system.
8. Supply habitats, farms and industrial consumers.

Industrial water extraction should provide substantially higher output than the starter recycling plant, while consuming more power and construction materials.

### Phase 9 — Nuclear energy

Introduce advanced nuclear energy as a high-tier technology.

Buildings:

- Imported modular nuclear reactor
- Advanced reactor
- Nuclear fuel storage
- Heat rejection system

Provide an abstract nuclear fuel resource and maintenance system.

Reactors require fuel, maintenance and functioning electrical connections.

Nuclear plants generate continuous electrical output while operational.

Reactor faults should cause safe shutdowns and repairs, not detailed nuclear accident simulations.

Do not model real reactor manufacturing, uranium enrichment or other sensitive engineering processes.

Use gameplay abstractions for fuel processing.

Nuclear power must connect to the existing electrical network.

### Phase 10 — Rocket propellant

Add a rocket fuel production objective.

Production chain:

1. Extract water ice.
2. Purify water.
3. Produce hydrogen and oxygen through electrolysis.
4. Capture atmospheric CO₂.
5. Manufacture methane.
6. Liquefy methane and oxygen.
7. Store both in suitable cryogenic tanks.
8. Deliver fuel to a launch facility or Starship terminal.

Treat liquid methane and liquid oxygen as separate resources.

Introduce fuel contracts for future trade and spacecraft resupply gameplay.

No rocket flight physics are required for this release.

### Phase 11 — Industrial interface

Add the following UI features:

- Geological map overlay
- Survey drone management
- Mineral deposit inspector
- Mining construction category
- Industry construction category
- Automated logistics dashboard
- Drone fleet dashboard
- Resource production and consumption panel
- Manufacturing recipe selector
- Storage inventory overview
- Power demand overview
- Production shortage alerts

The player must be able to follow a resource from its deposit through mining, transportation, refinement, manufacturing and storage.

### Phase 12 — Performance

The map must support at least 512 × 512 logical tiles without rendering all tiles every frame.

Use:

- Chunk-based rendering
- Viewport culling
- Sprite pooling where appropriate
- Batched terrain graphics
- Incremental connectivity updates
- Efficient pathfinding
- Cached resource overlays
- Simulation updates independent of rendering

Avoid repeatedly scanning the entire world for every drone or production tick.

Set measurable performance tests for larger colonies.

### Phase 13 — Saves and compatibility

All new systems must persist.

Save:

- Map seed and chunk state
- Discovered terrain
- Survey results
- Mineral deposits and remaining reserves
- Mines and factories
- Drone positions, cargo and jobs
- Storage inventories
- Production jobs
- Manufacturing recipes and progress
- New pipeline networks
- Nuclear power state
- Rocket fuel inventories

Implement schema-versioned migrations.

Existing player colonies must continue loading correctly.

Derived network connections and job indexes may be rebuilt on load.

### Phase 14 — Testing and acceptance criteria

Create automated tests covering:

- Deterministic large-world generation
- Old colony map expansion
- Scanner detection
- Hidden deposits remaining undiscovered
- Mine placement restrictions
- Deposit depletion
- Drone job assignment
- Rover transport and cargo conservation
- Charging and battery depletion
- Factory input consumption
- Refinery production
- Water-ice extraction
- Methane production
- Nuclear electricity generation
- Pipeline isolation
- Storage capacity limits
- Save/load persistence
- No duplicated resources following reload
- Performance on a 512 × 512 world

## Required development order

Do not attempt the entire release in one implementation pass.

Build and verify in this order:

1. Large-world support and map migration.
2. Resource deposits and scanning.
3. Survey drones and exploration.
4. Mines and extraction.
5. Cargo logistics and storage.
6. Refineries.
7. Battery and solar manufacturing.
8. Industrial water extraction.
9. Hydrogen and methane production.
10. Nuclear energy.
11. Rocket fuel and production objectives.
12. Visual polish, balancing and Railway release preparation.

After every phase:

- Run the existing tests.
- Add relevant new tests.
- Verify the build.
- Preserve prior features.
- Report changes and outstanding work.

Do not deploy an unverified build to production.

## V0.3.1 success condition

The player must be able to discover a mineral deposit, construct a mine, assign automated drones, extract ore, move it to storage, refine the material and use it to manufacture a valuable product.

At least one complete battery manufacturing chain must work.

Industrial water extraction and methane production must also be operational.

Nuclear energy must provide an additional electricity source.

All production must consume actual resources.

All existing survival, construction, pipe, cable, road, population and save systems must remain operational.

Provide a final report identifying completed features, tests, performance results, remaining limitations and readiness for deployment.
